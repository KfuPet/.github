## 🌈 关于我们

**KfuPet（快芙桌宠）** 是一个专注于「智能桌面伙伴」的开源组织。

我们相信，桌宠不该只是循环播放动画的桌面挂件，而应该是**有温度、会成长、能陪伴的智能生命体**。核心产品 KfuPet 基于 **WPF / .NET 8** 打造，将精致细腻的预设动画与 AI 驱动的行为系统深度融合，让每一次互动都鲜活自然。

- 🎨 **精美预设动画** —— 细腻灵动的桌面表现力
- 🤖 **AI 驱动行为** —— 更自然的交互与陪伴体验
- 🧩 **开放工具生态** —— 官方开发者工具 KfuPet Tool
- 🚀 **多镜像更新** —— 独立更新器，GitHub / GitCode / Gitee 智能选源
- 📄 **开源双许可** —— AGPL-3.0 与商业授权并行，社区友好

## 📥 立即下载

**KfuPet** 发布在 GitHub（主源），国内另有两个镜像（仅同步发行版附件），三个源版本一致，任选可访问的一个即可：

| 下载源 | 地址 | 说明 |
| --- | --- | --- |
| GitHub（主源） | [点击下载](https://github.com/KfuPet/KfuPet/releases/latest) | 版本最及时 |
| GitCode（国内镜像） | [点击下载](https://gitcode.com/Lrht/KfuPet/releases) | GitHub 访问不畅时优先使用 |
| Gitee（国内镜像） | [点击下载](https://gitee.com/lrht/kfu-pet/releases) | 紧急备用 |

> 下载 **`KfuPetInstall.exe`** 运行即可安装 / 升级，安装器会自动挑选可用源，装好后无需再手动找镜像。
>
> **开发者工具**：[KfuPet Tool 下载](https://github.com/KfuPet/KfuPet-Tool/releases/latest)
